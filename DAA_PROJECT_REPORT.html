2. Algorithm Formulations & Execution Mechanics
2.1 Dijkstra's Algorithm (Greedy Single-Source Shortest Path)

Finds shortest travel times from source s ∈ V to all vertices with non-negative edge weights (w ≥ 0). Maintains tentative distances dist[u] and priority queue Q.

Recurrence Relation:
alt = dist[u] + w(u, v)
dist[v] = min(dist[v], alt)
prev[v] ← u   (if alt < dist[v])

Granular Pseudocode Execution Tracker:

  • Line 8 [alt = dist[u] + weight(u, v)]: Explicitly computes alternative candidate distance. Graph edge highlights in amber; distance table unmutated.
  • Line 9 [if alt < dist[v]:]: Evaluates conditional predicate. Decides whether candidate route beats prior shortest known time.
  • Line 10 [dist[v] = alt; prev[v] = u]: Executed strictly when condition is TRUE. Mutates distance table, triggers green glow and audio chord. If condition is FALSE, Line 10 is skipped.
  • Complexity: Time: O((V + E) log V) | Space: O(V).
2.2 Bellman-Ford Algorithm (Dynamic Programming / Relaxation Passes)

Relaxes all |E| directed edges iteratively over |V| − 1 passes. Supports negative weights and guarantees detection of negative cycles.

Recurrence Relation (Pass k ∈ [1, |V|-1]):
d(k)[v] = min( d(k-1)[v],   min(u,v)∈E { d(k-1)[u] + w(u, v) } )
Negative Cycle Rule: ∃ (u,v)∈E : dist[u] + w(u,v) < dist[v] ⇒ Error (Negative Cycle)
  • Early Convergence: If a pass produces zero relaxations, algorithm halts immediately.
  • Complexity: Time: O(V • E) | Space: O(V).

2.3 Floyd-Warshall Algorithm (All-Pairs Dynamic Programming)

Computes all-pairs shortest paths across the 5x5 transit matrix using bottom-up 3D dynamic programming over intermediate vertices k ∈ {1, ..., |V|}.

3D Recurrence Relation:
D(k)[i, j] = min( D(k-1)[i, j],   D(k-1)[i, k] + D(k-1)[k, j] )
Π(k)[i, j] = Π(k-1)[k, j]   (if path via k is shorter)
  • Complexity: Time: Θ(V3) (exactly 53 = 125 operations) | Space: Θ(V2) (stored in 5x5 table).

6. Conclusion

This project demonstrates that greedy assumptions frequently fail on single-hop campus roadways, making multi-hop graph optimization indispensable. Dijkstra delivers rapid single-vehicle dispatch, Bellman-Ford validates network stability, and Floyd-Warshall precalculates all-pairs transit schedules. The accompanying live visualizer provides exact line-by-line verification of algorithmic correctness.
